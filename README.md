# 7-3 · Fundamentos de la Alfabetización Digital

Sitio estático con recursos y tareas para la clase de 7-3 de la Escuela
Arianys Nicole Rosa Luquis. Sin backend ni datos personales.

## Contenido

- `index.html` — portada con los enlaces.
- `hw/canva.html` — guía de la presentación en Canva: cuántos slides y qué
  poner en cada uno, con una guía personalizada por grupo.

## Publicación

GitHub Pages desde la rama `main`, carpeta raíz. URL:
`https://kevinaming.github.io/7-3/`

## Probar localmente

```bash
python3 -m http.server 8000
```

y visitar `http://localhost:8000`.
